# 🎮 DX-Boy

**A web-based Game Boy emulator developed by DougX.**

DX-Boy is a browser-based Game Boy emulator featuring a custom interface, responsive controls, and a console-inspired experience for both desktop and mobile devices.


🌐 **Play DX-Boy:**
https://dougrocha1.github.io/dx-boy/

---

## ✨ Features

* 🎮 Game Boy emulation directly in the browser
* 📱 Mobile-friendly interface
* 💻 PC keyboard controls
* 🕹️ On-screen controls for mobile devices
* 🎛️ Adjustable control layout and size
* 🔊 Custom DX-Boy startup sound
* 💾 Game save support
* 📂 ROM loading through the interface
* 📡 Bluetooth controller support
* ⚡ Optimized for a smooth browser experience
* 🎨 Custom DougX Boy visual design

---

## 🕹️ Controls

### PC

| Key     | Action |
| ------- | ------ |
| ↑ ↓ ← → | D-Pad  |

| Z       | B      |
| Enter   | START  |

### 📱 Mobile

DX-Boy provides on-screen controls designed for touchscreen devices.

Use **ADJUST CONTROLS** to:

* Move the virtual controls
* Resize the buttons
* Customize the layout to your preference

---

## 🔊 Audio

DX-Boy includes its own custom startup sound created for the project, replacing the original startup audio with a unique DougX experience.

---

## 💾 Save System

DX-Boy supports compatible Game Boy game save data.

Save progress is handled by the game itself, just like on the original hardware. DX-Boy preserves compatible save data so your progress can be retained between sessions.

---

## 📱 Desktop & Mobile

DX-Boy was designed to work across different screen sizes.

The interface adapts to mobile devices while preserving the look and feel of a dedicated handheld console.

---

## 🚀 Getting Started
